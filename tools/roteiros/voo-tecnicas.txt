# Voo de combate: as técnicas do Goku travado no Vegeta (Stark 2026-11-13: mira totalmente errada, Kaioken rush sem alvo).
# Kamehameha (Z segurado), Teleporte (X), Kaioken + rush (C, C), Genki Dama curta (V). A mira tem que ir no Vegeta.
# Pré-requisito: mundo SoulsDev dos testes do voo (técnica voo aprendida, alma Goku tier 6 = mesmo tier do Vegeta).
# /devc tecla X N não espera os N ticks: cada tecla segurada vem com espera.
# Rodar: gradlew runClient -Pmundo=SoulsDev -Proteiro=voo-tecnicas
/devc fechar
/dev soltar
/kill @e[type=!player]
/time set day
/weather clear
/gamemode survival
/effect give @s resistance 99999 3 true
/effect give @s saturation 99999 0 true
# a alma pode ter trocado numa rodada anterior (Vegeta morto = alma dele tomada): volta pro Goku tier 6
/soul escolher goku
/soul tier 6
/soul semcooldown
/gamerule sendCommandFeedback false
# área nova (as de 0 -400 e 600 -600 ficaram cheia de crateras das rodadas anteriores)
/tp @s 1400 -40 -1400 0 0
/devc vista terceira
/devc janela 1280 720
/devc chat off
espera 30

# Decola (pulo duplo) e sobe
# toque duplo do vanilla: os dois espaços têm que caber em 7 ticks
/devc tecla espaco 2

/devc tecla espaco 2
espera 4
espera 10
# sobe só um pouco (com 25 ticks ia a 48 blocos do Vegeta, fora do alcance dele)
/devc tecla espaco 8

espera 10
